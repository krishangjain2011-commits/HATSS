# UI Design System

## Design Principles
- Dark-first interface
- Minimal, modern, professional
- Glassmorphism used sparingly
- Accessibility before aesthetics

## Color Palette
- Primary: Blue
- Background: Near black
- Success: Green
- Warning: Amber
- Danger: Red

## Typography
- Clear hierarchy
- Consistent spacing
- Responsive layout

## Components
Buttons, Cards, Tables, Alerts, Dialogs, Sidebars and Charts should share a consistent visual language.
